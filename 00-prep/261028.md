## 배운 것
- 경쟁사를 2-3개의 타깃 고객, 핵심기능, 강점과 약점 등을 표로 정리
  - 시장이 비슷할 때는 *기능 체크표(OX표)* 를 만든다
- **막대차트** 만드는 법: 요약표에서 '채널'과 '노출합계' 셀을 모두 드래그 후(ctrl 활용) 삽입 탭 -> 세로 막대형 차트
  - 요약표를 정렬하여 차트 또한 순서대로 서있게 하기
  - 메시지형 제목: 보는 사람이 차트 제목만 봐도 핵심을 알 수 있게
    - ex) CTR: 블로그, 인스타의 3배
- **조건부 서식**: 홈 탭 -> 조건부 서식 -> 데이터 막대 -> 셀 안에 막대가 생김
  - 기준 값보다 높은 칸 강조: 조건부 서식에서 셀 강조 규칙 -> 보다 큼
- 단순 값 복붙: 셀참조와는 다르게 원본이 바뀌어도 그대로. 
  - ctrl c, ctrl v 하면 수식이 복사되어 엉뚱한 값이 나옴
  - 우클릭 후 붙여넣기 옵션 "값" 선택
