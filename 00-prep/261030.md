## 배운 것
- 템플릿을 만들기 전에
  - 몇 장 구성, 각 장마다 제목과 내용을 미리 정하기
  - 표지(훅) -> 상황/문제 -> 해결(제품이 뭘 해주나?) -> 근거/사례 -> 마무리
  - 장마다 제목 15자 안팎 + 본문 2줄 이내
  - 핵심 메시지는 1개만. 제목과 본문은 같은 메시지를 전달
  - 사실 확인은 언제나 중요
  - 독자가 누구인지? 기업인지 개인인지
- SNS에서 보통 4:5 화면 비율 많이 사용 -> 템플릿 선정
- 마지막으로 폰으로도 글자가 보이는지 확인
- 기사 사진은 출처를 남겨도 사용 금지, 보통 회사 제공 사진 사용
