## 배운 것
- 숫자를 다루는 함수
  - SUM, COUNTA, COUNT, AVERAGE
    - COUNTA VS COUNT: COUNT는 숫자값이 입력된 셀만 센다
    - COUNT(F:F): F열 전체중에
  - SUBTOTAL(9, F:F): 주로 필터 적용했을 때 화면에 보이는 셀만 집계
    - 화면에 보이는 셀 수가 바뀔 수 있으므로 F:F처럼 전체 열을 써준다
  - RANK(순위를 매길 셀, 범위, 0): 0은 내림차순
- 텍스트를 다루는 함수
  - 쪼개기: LEFT, RIGHT, MID
    - LEFT, RIGHT(,N): 각각의 기준에서 N개의 글자를 가져옴
    - MID(,N,2)의 경우, 기준(N번째)과 글자의 개수
  - 합치기: CONCATENATE, &, 
    - CONCATENATE(D7," ",D8," ",D9) = D7&" "&D8&" "&D9
    - TEXTJOIN(구분자,TRUE,범위), CONCAT(범위)
      - 이 둘은 2019 이상 버전만 가능
  - 찾기: FIND, SEARCH - 비슷하나 SEARCH는 대소문자 구분안함
  - 바꾸기
    - SUBTITUTE(D13,"특별시","시")
    - REPLACE(D14,3,2,""): 3번째 글자에서 2개의 글자를 ""으로 바꿈
    - TRIM(): 맨앞 맨뒤 띄어쓰기 정리
- 페르소나, 고객 여정 지도, 문제 정의
  - 실제 데이터를 근거하여 만든 가상의 고객 페르소나가 제품이나 서비스를 인지하고 구매하고 추천하기까지의 단계
  - 고객 여정 지도에서 불편하거나 막히는 부분이 기회.
  - 이를 한 문장으로 정의하면 문제 정의
