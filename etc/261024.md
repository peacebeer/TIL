## GGDC 정리

### 게임 기획 잘하는 방법
AI 시대에 "인간이 병목이다"라는 말은 맞지 않다고 생각(강연자님 의견)  
AI 이전에는 개발에 들어가는 시간과 비용이 많이 들어가니 충분히 기획하고 고민했던 것. 오히려 이 병목을 잘 이용해야  
1. **내가 잘하는/좋아하는/더 하고 싶은 것을 얼마나 자세히 말할 수 있는지**    
   - 강연자 님의 경우 엣지노트를 10년간 작성
   - 근본적으로 내가 어떤 사람인지, 무엇을 좋아하는지 잘 아는 사람이 되어야 함
2. 구상 및 기획 단계에 시간을 더 써야
   - **기획서 대신 프로토타입(핵심으로 밀고 싶은 것)을 빨리 만든 후 재밌는지 검증하고 아니면 빨리 버리기**
   - 다른 분 강연에서도 "핵심을 보여줄 수 있는 빌드"를 먼저 만들고 보여주라고 언급
3. AI와 나 싱크 맞추기
   - 텍스트와 이미지로 AI에게 내 요구를 설명하기 보단 **툴을 만들어라**
   - 예) 오브젝트 위치와 기능을 제어하는 HTML 툴
   - 게임 1개 만드는데 툴 30개
   - 별개로 HTML로 AI와 ppt 만드는 법도 언급  



### 용어
- 성능 프로파일링: (게임의 경우) 게임이 실행되는 동안 CPU, GPU, 메모리, 디스크 I/O 등의 자원이 어떻게 사용되는지 측정하고 분석하는 과정  
- 쉐이더Shader: 컴퓨터 그래픽스에서 화면의 픽셀, 빛, 명암, 질감, 색상 등을 계산하고 렌더링 과정을 제어하는 프로그램. 게임의 최적화를 담당  
- 전환율 CVR: 광고의 효율성을 측정. $\frac{전환수}{클릭수}\times100$  
- CPI: Cost Per Install $\frac{총 광고 비용}{총 앱 설치수}$

## 배운 점
- 무엇을 만들 때, 핵심이 되는 것을 일단 만들고(AI의 도움으로 이게 굉장히 쉬워졌음) 아니면 바로 버릴 수 있는 결단이 있어야한다.
- 내가 어떤 사람인지, 무엇을 잘하고 좋아하는지에 대한 기록이 있어야한다.

  - 개발할 기회가 있으면 툴 만들어보기
  - 나의 취향에 대한 기록 남기기
